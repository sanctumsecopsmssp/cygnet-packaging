# cygnet-packaging

Cross-platform packaging for [Cygnet Provider](https://github.com/sanctumsecopsmssp/cygnet-provider) by Sanctum SecOps LLC.

## Installation

### macOS (Homebrew)
```sh
brew tap sanctumsecopsmssp/cygnet
brew install cygnet-provider
```

### Linux (Debian/Ubuntu)
```sh
curl -fsSL https://raw.githubusercontent.com/sanctumsecopsmssp/cygnet-packaging/main/install.sh | bash
```
Or manually:
```sh
sudo apt install ./cygnet-provider_0.1.1_amd64.deb
```

### Windows (winget)
```powershell
winget install SanctumSecOps.CygnetProvider
```
